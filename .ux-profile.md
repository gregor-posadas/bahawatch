# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom
- **Notes:** NYC subway signage (Unimark 1970 manual): black on white, one typeface, few sizes, two weights, colour only for meaning. Typeface: Atkinson Hyperlegible Next (and Mono for code), chosen for readers with low vision (Gregor, 2026-09-29), on the page, canvases, figures and map labels. Maps on warm "Mini Motorways" paper (#f8f4ec), white streets with sand casings, pastel creeks. Brand blues from the logo (#0030a0, #70c0e0). Status by shape + colour (Okabe-Ito palette). Figures: Jack Baker categorical palette (#385F96, #CF5921, #9EB8DB, #E7B800, #800000), Crameri colormaps (Davos sequential, Vik diverging), readable in grayscale, checked with a colour-blind simulation.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs

## Accessibility target

- **Level:** WCAG 2.1 AA, with larger touch targets
- **Contrast:** Text ≥ 4.5:1; large text, borders and map markers ≥ 3:1 — in both light and dark themes
- **Touch / focus:** Every tap target ≥ 48 × 48 px; 3 px brand-coloured focus ring; no page-level sideways scroll at 375 px and 390 px; screen-reader text for every map; motion off under `prefers-reduced-motion`

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal (plain and direct, like MMDA / PAGASA advisories)
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Six languages (English, Filipino, Cebuano, Ilokano, Hiligaynon, Kapampangan); non-English strings are marked for native review until reviewed. Never blame the reader. Always say what is simulated.

## Icon library

- **Library:** Project SVG
- **Package / path:** Inline SVG in `template.html`; text glyphs ☾ ☀ ▾ ‹ ⌂ + − for controls
- **Notes:** No icon package. One set only; no emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
